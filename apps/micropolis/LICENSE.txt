Micropolis for TaterOS
======================

This folder is a lightly modified build of micropolisJS by Graeme McCutcheon
and contributors, itself a port of Micropolis, the open-source release of
the original 1989 SimCity source code.

  Upstream source: https://github.com/graememcc/micropolisJS
  Built from commit: f13a1624d111d235e804bd80f48ba7c9f66a8e0f
  Build: `npm ci && npx webpack --mode production --no-optimization-minimize`

src/micropolis.js is the unminified webpack bundle (it includes jQuery 3.7.1,
MIT licensed). The complete corresponding source is at the commit above.

Changes made for TaterOS (this is a modified version, not the original):
  - index.html: retitled, Twitter widget removed, text tweaks, license links
  - tater.css: Win95-style skin layered over the upstream stylesheet
  - The game code itself is unchanged.
