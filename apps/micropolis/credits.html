Credits & License

Micropolis for TaterOS is a lightly modified build of micropolisJS by Graeme McCutcheon and contributors. micropolisJS is a port of Micropolis, the open-source release of the original 1989 SimCity source code.

Where this build came from

Upstream source: github.com/graememcc/micropolisJS
Built from commit f13a1624d111d235e804bd80f48ba7c9f66a8e0f
Build: npm ci && npx webpack --mode production --no-optimization-minimize

src/micropolis.js is the unminified webpack bundle. It includes jQuery 3.7.1 (MIT licensed). The complete corresponding source is at the commit above.

Changes made for TaterOS

This is a modified version, not the original:

  • index.html: retitled, Twitter widget removed, text tweaks, and the header links and bottom bar moved to this page and Thanks.
  • tater.css, credits.css: a Win95-style skin layered over the upstream stylesheet.
  • credits.html, thanks.html: these pages.
  • The game code itself is unchanged.
